# 오픈소스 AI 웹사이트 (기본 틀)

정적(Static) HTML/CSS/JS로 만든 최소 뼈대입니다. 빌드 도구 없이 바로 실행할 수 있어요.

## 실행

- `index.html`을 더블클릭으로 열기
- 또는 VSCode/Cursor에서 Live Server로 열기

## 구조

- `index.html`: 홈
- `pages/about.html`: 소개 페이지
- `css/styles.css`: 공통 스타일
- `js/main.js`: 공통 스크립트(네비게이션 활성화, 테마 토글 등)
- `assets/`: 이미지/아이콘 자리
